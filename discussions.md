# Discussions — user ↔ root-agent conversation log only

**Reorganized 2026-09-16.** This file grew into a general dumping ground for cross-peer-session technical findings during one long overnight push — that was a deliberate, explicitly-acknowledged exception at the time ("desperate times call for desperate measures"), not the intended shape. It's over now. Every resolved technical finding and every still-open design question that used to live here has been moved into the relevant repo's own knowledge-graph files (see `README.md`'s index, and each repo's `TASKS.md`/`ML-NETWORK-DESIGN.md`/`VM-BOOT-SAGA.md` for `noxos-app`). Nothing was summarized away — root causes, commit hashes, exact numbers, and error text moved intact to their owning repo.

**Going forward, this file is exclusively for the user ↔ root-agent (this session) conversation and decision record** — not a relay channel for peer-session cross-talk, and not a technical archive. If a peer session's finding needs recording, it goes directly into that repo's own `TASKS.md` (or a same-repo dedicated file if the topic warrants one), not here. Peer sessions maintain their own `TASKS.md` in real time — this file was never meant to duplicate that.

Nothing currently open here as of the reorg — everything either resolved into a per-repo file or is already tracked as a live backlog item in the relevant repo's `TASKS.md`.
